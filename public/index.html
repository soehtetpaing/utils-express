Genius Utils REST

v1.0.2
Genius Utils is a comprehensive utility library built to provides modern tools for full stack development. Designed for developers, it simplifies automated query script version migration (with mssql, postgre, mysql database support), media management, device information retrieval, logging, API token generation and verification (with specific domain support) and date/time formatting. The library is developed with both Node.js and Spring Boot environment version supports.
